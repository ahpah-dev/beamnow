03 / THE ANATOMY OF RESTRAINT

Everything an agent needs. Nothing it doesn’t.

Built in ~1,500 lines of clean Rust. No Electron wrapper, no background daemons, no mandatory cloud login.

I.

Zero-Key Onboarding

Launch beamnow.exe and start coding immediately. Out of the box, BeamNow routes through Kilo Code’s free gateway (kilo-auto/free) and indexes zero-cost tool-calling models from OpenRouter at startup.

Ready for BYOK? Add keys for Anthropic, OpenAI, NVIDIA NIM, DeepSeek, or point at local Ollama / vLLM / LM Studio endpoints.

II.

Six Surgical Tools

The agent operates directly inside your chosen workspace with six focused primitives: read_file, write_file, edit_file, list_dir, grep, and run_shell.

Every mutating action or shell command pauses for inline human approval right inside the transcript—unless you switch to Auto-approve.

III.

Public Domain Forever

Great developer tools should belong to the commons. BeamNow is dedicated to the public domain under The Unlicense. Fork it, embed it, theme it, or ship it inside your own workflow with zero restrictions.

Single binary · Local JSON session history · Human-readable TOML configuration.
